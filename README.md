Historical dashboard artifact exploring how opening range structure, VWAP relationship, and gamma regime context were rendered into a bounded interpretive surface.

## What is preserved

- **The dashboard surface** first: **HOSTAGE STATUS** (including **GEX Regime**, **GEX Confidence**, score rows, and related table copy) and optional **SPY/QQQ index tiles** carrying **ORB** wording, **VWAP** position text, and shared **GEX regime** labels.
- **Supporting narrative** under `docs/`: intent, how that surface coheres, **Regime Mode**, and the sequence of inquiry.

## How to read this material

Treat the tree as **archival**. Read **what the table and tiles display** before inferring how **A-side** checkpoints and **C-side** toggles (including **composite ORB** handling) combine under **Regime Mode** (MANUAL / AUTO / HYBRID). **Regime context** is session- and environment-dependent; caption rows on **HOSTAGE STATUS** are **preserved wording** on the artifact, not timeless mandates.

This record documents **interpretive stance and layout choices** bound to the saved file, not chart-external setup.

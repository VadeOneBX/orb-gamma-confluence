# Orb–gamma confluence (historical research artifact)

This repository preserves a **dashboard-centered research thread**: a fixed visual and conceptual surface used to study how opening-range structure, gamma-related readings, and other inputs **cohere** in retrospect—not to instruct live action.

## What is preserved

- **The dashboard** as the durable output: a composed view that encodes design choices, comparative framing, and the questions the work was meant to support.
- **Supporting narrative** under `docs/`, describing intent, architecture, scoring posture, constraint logic, and the sequence of inquiry.

## How to read this material

Treat the tree as **archival**. Confluence constructs are **research surfaces** for interpretation; constraints are **design variables** in an exploratory space, not certified boundaries; regime language is **environment-dependent** and must be read in the context of the period and data regime assumed in the work—not as a timeless label.

This artifact **does not** document provider configuration, execution procedures, broker connectivity, automation scaffolding, or deployment. Those topics were intentionally out of scope for the preserved narrative.

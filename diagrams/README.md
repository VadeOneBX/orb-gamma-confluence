# Diagrams

This directory holds **conceptual illustrations** aligned with the preserved dashboard narrative: structure, flow of attention, or relationships between layers as **documented in prose**, not as executable models.

## Dashboard Surface Architecture

The preserved Pine artifact renders multiple contextual layers into a
bounded dashboard surface.

Structure → Opening Range  
Context → Gamma Regime  
Alignment → Confluence Surface  
Output → Dashboard Tiles

Diagrams are **archival aids** for reading the artifact. They do not prescribe tooling, environments, or operational steps; they clarify **how the research was organized** at the level of ideas and layout.

Treat figures as **secondary to the written shelf and overview docs**—helpful for orientation, not substitutes for the full framing.

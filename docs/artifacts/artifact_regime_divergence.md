# Artifact: regime divergence

This entry names **interpretive divergence** when the same composites or readings are read against **different environment assumptions**—liquidity, volatility, session structure, or data character—implicit in different phases of the work.

**Divergence** is framed historically: the same numerical object can **mean differently** when the assumed regime shifts. The artifact preserves **that sensitivity** as a caution on reading, not as a map from labels to action.

Regime language here is **context for interpretation**, not a separate engine or classification mandate.
